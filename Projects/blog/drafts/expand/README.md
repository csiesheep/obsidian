## 要你確認的句子

- **64**：Blogger 的「搜尋說明」設定位置是依較舊的教學寫的，目前介面的選單名稱可能不同，建議實際點一次確認。
- **218**：「這些帳號現在還有沒有在動，我沒有一個個去確認」：這句是描述這次補記的做法，若你有去看過這些帳號，請改寫。
- **32**：2011 年玩的是第二版還是其他版本？文中沒寫版本，如果記得可以補一句。
- **7**：原文標題寫「日劇」，補記假設當年看的是 2008 年富士台日劇版（生田斗真主演），請確認。
- **641**：commit 數：repo 到 2026-09-05 為止 git log 共 696 個（含 08-14 起和《Zombie》共用的歷史），08-22～08-30 是 586 個。工作日誌寫 08-28 當天 125 個、git 依日期算是 120 個，文中寫「一百二十幾個」，請確認口徑。
- **641**：文中提到「另一個結局很難碰到」，鎮屍是設計上的隱藏結局，要不要在部落格點到？若不想，刪掉「不只一種結局」那句。
- **641**：「第一次部署後聽到的是舊版本」這段是從工作日誌推的機制，確認你自己有遇到過再保留。
- **282**：延伸閱讀的兩個中文書名（《別讓統計數字騙了你》《深入淺出統計學》）是依印象寫的，請確認台灣譯名。
- **13**：結尾反思「『不打算打敗市場』這個方法，反而不太會因為大家都知道而失效」——確認不會被讀成投資建議。
