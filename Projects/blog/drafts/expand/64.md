## 2026 補記

這篇是 2010 年寫的，那時候覺得 SEO 就是一堆小技巧，tag 加對了就會被看見。

十幾年後回來看，結論比較無聊，但比較踏實~

### meta keywords：真的沒用了

原文最後說 Google 不用 meta keywords 排名，這件事到現在都沒變。

Google 是在 2009 年 9 月正式寫了一篇〈Google does not use the keywords meta tag in web ranking〉（[Google Search Central Blog](https://developers.google.com/search/blog/2009/09/google-does-not-use-keywords-meta-tag)）。

那原文擔心的 Bing 呢?

Bing 那邊後來的說法是：meta keywords 是它看的上千個訊號之一，但比較像是拿來**抓 spam** 的訊號，亂塞關鍵字反而可能被扣分（[Search Engine Land](https://searchengineland.com/the-meta-keywords-tag-lives-at-bing-why-only-spammers-should-use-it-96874)）。

所以原文那段「跪求怎麼用逗號分隔 keywords」，現在的答案是：不用分隔了，直接刪掉 XD

### description：還有用，但不是拿來排名

description 不一樣，它還有用，只是要搞清楚用在哪：

- Google 的文件只在「搜尋結果摘要 (snippet)」的段落講它，沒有說它會影響排名。
- Google 主要是從頁面內容自己產生摘要，只有在它覺得 description 比內文更能說明這一頁的時候，才會拿來用。
- 每一頁都一樣、或很相似的 description 是沒有幫助的，最好每頁寫不同的（[Google：控制搜尋結果摘要](https://developers.google.com/search/docs/appearance/snippet)）。

原文的作法是 `blog.title + blog.pageName`，也就是「部落格名稱 + 文章標題」。

現在回頭看，這剛好就是 Google 說的「每頁都很像」的那種 description orz

標題本來就會顯示在搜尋結果上，description 再重複一次標題，對讀者來說沒有多一點資訊。

比較好的寫法，是想像讀者在搜尋結果裡只看得到這兩行：他看完，能不能知道點進來會得到什麼答案?

### 現在 Blogger 要怎麼做

後來 Blogger 自己在設定裡加了「搜尋說明」(search description) 的選項，打開之後，每篇文章的「文章設定」裡可以各自填一段說明。

所以已經不需要去改 template 的 HTML 了。

如果今天要寫一個新的部落格，我會這樣做：

- 不寫 meta keywords。
- 重要的文章，自己寫一兩句 description，講「這篇解決了什麼問題」，而不是再重複一次標題。
- 把大部分的力氣，花在內文本身：標題清楚、內容真的回答了讀者想問的問題。

### 現在回頭看

我讀《漫步華爾街》時寫過一句：「當一個方法被所有人知道的時候，就是那個方法失效的時候。」

meta keywords 剛好就是一個例子：大家都知道塞關鍵字有用，於是大家都塞，於是它就沒用了，最後甚至變成抓 spam 的線索。

我覺得 SEO 的小技巧大概都逃不過這個命運。

能留下來的，大概只有一件事：對讀者有用的內容。

真的嗎?至少到目前為止，看起來是這樣 :p
