# 兒時回憶遊戲點子

一連串兒時回憶的小遊戲。簡單、休閒。

---

## 一、系列定位

- **一個手勢、三分鐘一局、不需要教學文字。** 小時候這些遊戲沒人教,看一眼就會了。
- **共用美術:作業簿、鉛筆線、藍色原子筆。** 手繪風,成本低,系列感一致。
- **主題是「無聊時自己發明的遊戲」**,不是泛泛的懷舊。用這條線篩選之後要收哪些點子。

---

## 二、車窗跑者

> 原始回憶:坐在車上看窗外,用手指假裝在車外跑步,遇到電線桿要跳過。

**核心差異:速度不歸玩家管,歸車子管。** Chrome 小恐龍是越跑越快,這款是爸爸在開車。紅燈會停下來喘口氣;上高速公路變快;塞車時走走停停,節奏變得很怪。

- **操作**:只有一個動作。點一下跳,長按跳得高。
- **畫面分三層視差**:遠山和房子慢慢動;電線桿和路牌很快掠過;最前面是車窗框和手指小人。
- **小人跑在電線或護欄上。** 電線在兩根桿子之間下垂再升起,小人跟著起伏。那條上下波動的線是這個回憶裡最有畫面的部分,比單純跳過桿子更值得做出來。
- **障礙物**:電線桿、路牌、行道樹、對向大卡車(整個遮住視線一秒)。進隧道時畫面全黑,只看得到玻璃上自己的倒影。
- **不設 Game Over。** 撞到只是踉蹌一下,連跳數歸零。一局就是一趟車程,兩到三分鐘,最後「到家了」結算最高連跳數。小時候沒有人會在這個遊戲裡輸。
- **路線當關卡**:回阿嬤家(鄉下,電線桿很規律)、市區(紅燈多、招牌多)、下雨天(車窗雨滴賽跑當彩蛋)。

---

## 三、紙上空戰

> 原始回憶:兩人對戰,在紙上畫飛機,用筆尖射,看飛機飛到哪;線穿過對方的飛機,對方飛機就毀掉。

**規則**:把筆尖立在自己的飛機上,手指壓住筆頭讓筆滑出去,在紙上留下一條線。線的終點就是飛機的新位置,線穿過敵機就算擊毀。

**最關鍵的設計:還原「滑筆」那種半控制、半運氣的手感。**

- 從飛機往後拖曳,決定方向(類似彈弓)。
- 按住蓄力,按越久滑越遠,但準心抖動也越大 → 「想打遠就要賭」的取捨。
- 放開後,線帶一點隨機弧度滑出去。**墨跡永久留在紙上**,打到後來整張紙都是線,這本身就是最好看的畫面。

其他規則:

- 每人三到五架飛機,輪流出手。
- 滑出紙外的懲罰:那架飛機墜毀,或只浪費這一回合 → **要試玩才能決定**。
- **開局讓玩家自己用手指畫飛機。** 碰撞範圍取筆畫的外框。幾乎沒有開發成本,但「自己畫的飛機被打爆」的感覺完全不一樣。
- 紙中間有一條摺線,兩邊各是一方的領地。之後可加手畫的雲或山當掩體。
- **對戰模式順序**:同機對坐(手機平放桌上,兩人面對面,跟當年玩紙一樣)→ 電腦對手 → 線上對戰。

## 四、系列候選

都符合「自己發明的無聊遊戲」這條線:

- [ ] 橡皮擦相撲:用手指彈橡皮擦,壓到對方的就贏
- [ ] 硬幣足球:三枚硬幣,每次要從另外兩枚中間穿過
- [ ] 走路只踩地磚,不能踩到線
- [ ] 車窗雨滴賽跑(可併進車窗跑者當下雨天模式)
- [ ] 原子筆圈地(點格棋)
- [ ] 尪仔標、彈珠

## 五、風險與下一步

**兩款的成敗都在手感,不在規則。** 車窗跑者要看跳躍搭配視差的感覺對不對;紙上空戰要看滑筆的蓄力和抖動。靠討論確定不了,要實際摸到才知道。
