# 紙上空戰 單人關卡:二十頁

草稿,還沒排進實作。畫面:https://claude.ai/artifact/ShgyNuicefBpbVEsha96wM(路線圖、翻頁、打一頁、第二十頁、破關,中英可切換)。

一本作業簿的二十頁,從隔壁的阿明打到老師。四章,每章五頁;每一頁最多加一樣新東西,每章第五頁是那一章的小考。

## 介面

- **路線圖是一張連連看。** 二十個點排成蛇形,四章各一排。破過的頁用藍筆連起來、旁邊蓋老師的紅章(甲上 / 甲 / 乙上);正在打的那頁虛線圈起來;沒到的頁只有鉛筆點和名字。每個點下面一個小塗鴉,是那一頁的機關(雲、山、洞、轟炸機、正字、小紙、老師的眼鏡)。
- 路線圖比手機長,往下捲;「翻到第 N 頁」按鈕在內容裡,不固定在底部([[owner-tests-on-real-iphone]] 的教訓)。
- **翻頁**:紙已經擺好,上面蓋一張便條:第幾頁、新東西(藍色標籤,沒有就不出現)、一句規則、對手和幾對幾、「開始」。
- **打一頁**:就是現在的紙,標題列改成「第 N 頁」,左上「‹ 路線圖」。
- **過頁**:打贏就過,下一頁解鎖;破過的頁可以重打刷章。章 = 剩下全部 → 甲上、剩一半以上 → 甲、其他 → 乙上。(現在對戰的評語是贏家剩 3 / 2 / 1 架,這裡改成比例,因為飛機數每頁不同。)
- **破關**:封面翻回來,蓋一個大甲上;成績單二十格,每格是那一頁拿到的章;老師的評語「很會玩。下次上課不要玩。」;統計(頁數、畫了幾條線、擊落、損失);「老師模式」(二十頁全部換成老師重打)和「回目錄」。
- 進度存 `localStorage`(每頁最好的章)。

## 新的規則零件

都是規則筆記「之後可以用資料加的變體」的延伸;雲和轟炸機原本就列在那裡,洞、小紙、老師是新的。

| 零件 | 規則 | 數字(草稿,要 harness 量) |
|---|---|---|
| 雲 | 線碰到雲的邊就停,飛機停在碰到的那一點;雲打不掉 | 半徑 55 到 85 |
| 山 | 沿摺線的一排,規則同雲,留一個缺口 | 缺口寬 130 |
| 破洞 | 線可以越過;線的盡頭落在洞裡,那架掉下去(同出界) | 橢圓約 46 × 34 |
| 轟炸機 | 命中半徑大、滑得遠、準心擺動大 | 命中 36、最遠 860、擺動 × 1.5 |
| 小紙 | 紙的大小是每頁的資料 | 420 × 630 |
| 手數 | 每頁的出手上限;兩邊用完比剩下的飛機,平手不算過頁 | 10 / 12 |
| 老師 | 新等級:瞄準雜訊 ±1°,每兩回合出手一次,紅筆 | ±1° |
