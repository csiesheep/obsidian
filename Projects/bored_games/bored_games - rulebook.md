# 無聊遊戲簿 — 規則筆記

這個系列沒有出版品規則書,規則來自 owner 的兒時記憶和試玩過的手感原型。這份筆記就是規格:引擎測試的 group 0 常數從這裡抄,不從產品讀。

來源:[[childhood game ideas]]、手感原型 https://claude.ai/artifact/T1BzBXJKrmmY6F7hkSAgSP(owner 2026-09-19 試玩:可以)。

## 一、紙上空戰(Paper Dogfight)

### 原始玩法(紙和筆)

兩個人,一張紙對摺,各自在自己那一半畫飛機。輪到你時,把筆尖立在自己的一架飛機上,一根手指壓住筆頭,讓筆往前滑出去,在紙上留下一條線。線穿過對方的飛機,那架就毀了。線的盡頭是你那架飛機的新位置。先把對方打光的人贏。

### 配件

| 項目 | 數量 | 說明 |
|---|---|---|
| 紙 | 1 張 | 邏輯座標 600 × 900,直放;摺線在 y = 450 |
| 飛機 | 每人 3 架 | 下方玩家(座位 0)藍筆,上方玩家(座位 1)黑筆 |
| 墨跡 | 不限 | 每次出手留下一條,永久留在紙上,純裝飾,不影響規則 |

### 開局

| 項目 | 值 |
|---|---|
| 每人飛機數 | 3 |
| 飛機起始 x | 120、300、480,各自 ±40 隨機 |
| 飛機起始位置離自己紙邊 | 90 到 260 隨機(座位 0 從 y = 900 往上算,座位 1 從 y = 0 往下算) |
| 起始朝向 | 朝對方 |
| 先手 | 隨機(每一局由種子決定,兩個座位各一半;owner 裁決 csiesheep/bored_games#4,2026-09-19:「randomly who is the first.」) |

### 回合

1. 選自己一架還活著的飛機。
2. 決定方向(任意角度)和力道 `pr`(0 到 1)。
3. 線從飛機目前位置滑出去。引擎用種子亂數決定長度誤差和弧度。
4. 線上任何一點離對方某架活著的飛機中心不到命中半徑,那架就毀掉。一條線可以毀掉不只一架。自己的飛機不會被自己的線打到。
5. 出手的飛機移到線的盡頭,朝向變成線尾的方向。
6. 線的盡頭如果在紙外,出手的那架墜毀。
7. 換對方。

### 出手的數值

| 項目 | 值 | 說明 |
|---|---|---|
| 最短距離 | 100 | `pr = 0` |
| 最遠距離 | 740 | `pr = 1` |
| 名目長度 | `100 + (740 − 100) × pr` | |
| 長度誤差 | × (0.94 到 1.06) | 均勻分布,引擎亂數 |
| 弧度 | 側向偏移 = `curv × len × s²`,`curv` 在 ±0.10 | `s` 是沿線 0 到 1;越到後面偏越多 |
| 線的取樣點 | 31 點(30 段) | 命中判定逐點檢查 |
| 命中半徑 | 24 | 對飛機中心 |

### 輸入手感(只在前端,不進引擎)

| 項目 | 值 |
|---|---|
| 蓄滿力道的時間 | 1.6 秒 |
| 筆自己滑出去 | 蓄滿後撐到 1.45 倍時間(2.32 秒) |
| 準心擺動幅度 | 1.5° 起,隨 `pr²` 長到 14° |
| 擺動波形 | `0.6·sin(7.3t) + 0.4·sin(11.9t + 1)`,平滑可預測,抓時機放開是技術 |
| 方向提示 | 只露出名目長度的前三成 |
| 取消 | 拉回飛機 18 以內放開 |

引擎收到的動作是 `{plane, ang, pr}`,`ang` 已經含擺動。擺動和蓄力是前端的事;bot 直接給 `ang` 和 `pr`。

### 自己畫的飛機(只影響外觀)

> orchestrator 裁決(csiesheep/bored_games#8,2026-09-19),依據未知數 #4 和計畫的「自己畫飛機進 v1」。上限是為了房間:畫是別人送來的資料,引擎要能拒絕。

| 項目 | 值 | 說明 |
|---|---|---|
| 一張畫 | 幾條筆畫;一條筆畫是幾個 `[x, y]` | 開局時給,`setup(seed, {art: [[座位 0 的三張], [座位 1 的三張]]})`;某一張給 `null` 就用預設的飛機 |
| 框 | x、y 都在 −1 到 1(含邊) | 機頭朝 −y;畫面上縮放進固定的框,再照飛機的朝向轉 |
| 筆畫上限 | 16 條 | 超過就拒絕整個 setup |
| 點數上限 | 一張畫 400 個點 | 同上 |
| 精度 | 存進 state 時四捨五入到小數三位 | 讓 state 小、重播穩定 |
| 對規則的影響 | 沒有 | 命中半徑固定 24;同一個種子、同一串手,有畫沒畫結局一樣 |

### 勝負

- 對方沒有活著的飛機,你贏。
- 同一次出手打光對方、自己那架又飛出紙外:出手的人贏(先打光對方的人贏)。
- 自己最後一架飛出紙外、對方還有飛機:對方贏。

### 記憶和原型沒講清楚的地方

這些是引擎測試要釘死的未知數,v1 的裁定寫在右欄。

| # | 問題 | v1 裁定 |
|---|---|---|
| 1 | 兩邊一直打不中,遊戲會不會沒完沒了? | 每人最多出手 30 次。到上限時活著的飛機多的人贏,一樣多就平手。 |
| 2 | 毀掉的飛機殘骸會不會擋線? | 不會。殘骸留在紙上當裝飾。 |
| 3 | 舊的墨跡有沒有作用? | 沒有,純裝飾。 |
| 4 | 自己畫的飛機,畫小一點是不是比較難被打中? | 不是。命中半徑固定 24,畫的圖縮放進固定的框,只影響外觀。 |
| 5 | 先手優勢多大? | M2 量到的是**後手**優勢(同級對打先手只贏 24–38%,bot 越會打越明顯)。owner 裁決(#4):誰先手改成隨機,數值不動。 |
| 6 | 飛機能不能停在對方那一半? | 可以。往前挪再近距離開火是這個遊戲的策略。 |
| 7 | 線的盡頭剛好在紙邊上算不算出界? | x 在 [0, 600]、y 在 [0, 900] 之內(含邊)算在紙上。 |

### 之後可以用資料加的變體(不在 v1)

- 每人 5 架;不同大小的紙。
- 手畫的雲或山當掩體(線碰到就停)。
- 轟炸機(命中半徑大、可以滑比較遠)。
