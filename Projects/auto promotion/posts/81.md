**《生在中國》古代投胎模擬器小改版：每一世結束，由 Claude 寫人生小傳；另加 1,000+ 張水墨圖**

玩玩看：https://games.csiesheep.com/china_life/

**一、線上用 Claude 寫小傳**
Claude 訂閱有附 API credits，不用白不用。先寫好 prompt，每次玩完呼叫 claude-haiku-5-5，寫 180～240 字小傳。
‧ 一篇約 0.0013 美元，每天上限 1,000 篇
‧ 伺服器會核對年紀、年份、事件；不對重寫一次，再不對就退回遊戲自己寫的版本

**二、1,000+ 張水墨圖**
Claude Code 接 ComfyUI，在自己電腦畫。難的是「對不對」：逃荒的男人挑著滿籃、清朝遠景有火車、牌匾是亂碼、明代人物穿盤扣、民國教室有日光燈。我一張張看、一張張重畫。

**三、做法**
我開 Claude Code 當統籌，子 agent 各在自己的 worktree 畫圖、寫引擎、測試；驗收時故意弄壞一次，確認檢查真的會轉紅。
