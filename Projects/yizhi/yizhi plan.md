# 易幟 yizhi - plan

> [!info] 點子階段(2026-09-30)
> 還沒有 repo、沒有規則書。這份筆記把「縱橫的國共內戰版」寫到可以決定要不要做的程度。
> 名稱「易幟 / Yizhi」和 slug `yizhi` 都是暫定,owner 定案前不要拿去開 repo。
> 地圖、牌表都是草稿 v0,沒有跑過任何一局。

## Overview

**易幟**是 [[zongheng plan|縱橫]] 的姊妹作:同一副卡驅動骨架,搬到 1945 到 1949 年的國共內戰。
兩人、8 回合、60 到 90 分鐘。一樣是單機對 bot 或四碼房間,中英雙語,手機優先。

核心想法一句話:**縱橫的「五國」換成五個立場未定的地方實力派**。國民政府其實是中央軍加上一圈地方實力派的聯盟,
內戰的勝負有一大半是這圈人往哪邊倒。這剛好就是縱橫第二層地圖在做的事:

| 縱橫 | 易幟 |
| --- | --- |
| 秦(連橫):把六國一個一個拆掉 | **共軍**:把地方實力派一個一個打掉或策反 |
| 楚(合縱):把聯盟綁在一起 | **國軍**:把地方實力派綁在中央底下 |
| 滅國:秦控制某國全部據點,3 國即勝 | **易幟**:共軍控制某勢力全部據點,3 個即勝 |
| 相印:楚控制國都且堆到上限,5 國即勝 | **整編**:國軍控制該勢力首府且堆到上限,5 個即勝(軍令統一) |
| 平手楚勝(合縱只要擋住秦) | 平手國軍勝(劃江而治就是守住了) |

## Why this shape

1. **不對稱是現成的。** 共軍負有「必須贏」的責任,國軍守住就算贏。這和縱橫的秦楚關係一樣,
   所以勝利條件、平手規則、bot 的評估方向都不用重新設計。
2. **「易幟」同時涵蓋打下來和談下來。** 太原是打下來的,北平、綏遠、長沙、昆明是談下來的。
   引擎裡都是「控制該勢力全部據點」,差別交給牌:戰役牌是免費奇襲,起義牌是直接移除首府的影響力。
3. **省工。** 引擎、房間、bot 搜尋、UI 骨架都沿用,新的工作量集中在地圖、72 張牌、文字和美術。
   但不是零成本,見下面「沿用與要改的」。

## Rules in scope

**原則:v1 的規則就是縱橫現行規則書原封不動**(見 [[zongheng - rulebook]]),只換資料。
下面三條是題材逼出來、不改不行的地方,其餘一律不動,等 bot 數字說話。

1. **延安陷落不能等於輸。** 縱橫的「國都陷落」是回合末國都在對手控制下就敗。南京照用;
   但延安 1947 年 3 月失守,共軍沒有輸。提案:延安被控制時共軍民心 −3、中央移到西柏坡,
   兩處都在國軍控制下才敗。(縱橫當初模擬過「遷都」這個選項,沒採用;這裡要重跑。)
2. **起始不對等。** 1945 年國軍兵力和地盤遠大於共軍。提案:國軍開局影響力鋪得廣而薄(到處 1 到 2 點),
   共軍集中而厚(延安與解放區堆滿)。靠上限 S + 2 和「對手控制的據點扶植要 2 點」讓薄的地方容易被撬。
   目標仍是 45 到 55%,不做「史實上共軍必勝」的遊戲。
3. **變法軌兩套格名。** 純文字,規則不變。

不在 v1:城鄉雙層與鐵路補給(當初的點子 2)、馬歇爾調停的政治階段與內線諜報(點子 3)。骨架穩了再談。

## 地圖草稿 v0

27 個據點(縱橫 26),5 個記分區加中間派。形狀刻意貼著縱橫,這樣 bot 的評估和 UI 版面不用重來。
安定值與相鄰關係留給規則書;★ 是要衝(8 個,和縱橫一樣),◎ 是首府。

| 區 | 對應縱橫 | 分值 | 據點 |
| --- | --- | :---: | --- |
| 解放區(共軍本土) | 西土 | 2/4/6 | 延安(都)★、綏德、西柏坡、邯鄲、臨沂 |
| 華北(主戰場) | 三晉 | 4/8/10 | 北平◎★(綏)、張家口(綏)、天津★(綏)、太原◎(晉)、大同(晉)、石家莊★ |
| 東北 | 東方 | 3/6/8 | 哈爾濱、長春、四平、瀋陽★、錦州★ |
| 江南中原(國軍本土) | 南方 | 2/4/6 | 南京(都)★、上海、徐州、鄭州、武漢(桂) |
| 大後方 | 北疆 | 2/4/6 | 蘭州◎★(馬)、西寧(馬)、昆明◎(滇川)、成都(滇川)、桂林◎(桂) |
| 中間派 | 周室 | 不記分 | 中間派(與北平、上海、昆明相鄰) |

- 「解放區」和「大後方」都是當時的說法,不是嚴格的地理區;地圖本來就是示意圖。
- 桂系橫跨江南與大後方,和趙橫跨三晉與北疆是同一個設計。
- 起始草稿:共軍 延安 4、邯鄲 3、綏德 1、西柏坡 1、哈爾濱 1,追加 4 點放解放區或華北;
  國軍 南京 4、徐州 2、上海 1、武漢 1,追加 4 點放江南或東北(美軍空運接收)。再依上面第 2 條加上薄薄的一層。
- 沒上地圖的大城(西安、濟南、開封、重慶、廣州、長沙)用牌表現。

## 沿用與要改的

數字來自 2026-09-30 的 `zongheng` repo。

| 部分 | 現況 | 易幟要做的 |
| --- | --- | --- |
| `engine.js`(1,506 行) | 寫死的區與據點 id 只有 9 處 | 幾乎照搬;加延安遷都那一條 |
| `board.js`(74 行) | 純資料 | 整份重寫 |
| `cards.js`(403 行) | 寫死的據點 id 43 處、區 id 34 處 | 每張重新指定目標;新效果 10 到 15 張 |
| `bots.js`(862 行) | 寫死的 id 只有 4 處 | 搜尋照搬;評估權重要用 sim 重調 |
| `app.js`(4,140 行)、地圖、i18n、規則頁、教學、音效、美術 | 都是縱橫的內容 | 骨架沿用,內容全換。這是最大的一塊 |
| `tests/`(約 90 個測試檔) | 很多以牌名命名(田單、荊軻、張儀) | 規則測試可搬,牌的測試要跟著牌重寫 |
| `src/room.js` | 與題材無關 | 照搬 |

**開新 repo,從縱橫 fork**,不做成縱橫裡的一個主題包。理由:站上每個遊戲都是自己的 repo 和自己的 Worker;
而且規則一定會分岔(延安那條就是第一個),共用一份引擎會讓縱橫的 90 個測試替易幟背書,那是假的綠燈。

## Bots and balance

- harness 沿用 `tests/sim.js`,目標和縱橫一樣:普通對普通,共軍勝率 45 到 55%;沒有任何一種結束方式低於 5% 或高於 50%。
- 第一輪要回答的 cell:起始鋪法(薄層幾點)、延安規則(敗 / 遷都 / 無)、易幟 3 個還是 2 加 1 個首府、整編 5 個還是 4 個。
- 縱橫學到的教訓直接帶過來:先修 bot 的蠢步再信數字(#132、#134 兩個 bot 錯誤曾經讓相印的結論整個反過來)。

## Open questions

1. **名稱。** 「易幟」暫定。其他候選:江山、逐鹿、山河。
2. **誰坐秦的位子。** 本文假設共軍是進攻方、國軍是聯盟方。反過來(國軍剿共、共軍結統一戰線)也說得通,但平手規則會變彆扭。
3. **延安規則**用哪一版(見 Rules in scope 第 1 條)。
4. **東北沒有地方勢力**,而縱橫的東方有齊。易幟只能在華北(綏、晉)和大後方(馬、滇川、桂)拿,東北變成純記分區。要看 sim 裡東北會不會沒人去。
5. **民生軌共用還是各一條。** 共用是照搬;各一條(國軍的通膨)比較貼題材,但那是點子 2 的範圍。
6. **題材敏感度。** 站上有流量統計和入口平台,這個題材在兩岸都有立場。用字中性之外,要不要在首頁加一句說明。
