這是一個非常棒的專案構想！「台灣好康地圖」的核心挑戰在於**資料的即時性**與**結構化程度**。許多大型連鎖店的促銷資訊是動態變動的（例如：每週幾、特定時段、特定門市），且分散在不同平台。

以下針對四大類別進行詳細評估。請注意：門市數為 2023-2024 年間的估算值，實際數字會隨開店/關店波動；網址與 API 狀態可能隨技術更新而改變，標註「不確定」處建議開發前進行實測。

### 總結與建議

#### 1. 哪些店家最適合第一版地圖？

*   **首選：全聯福利中心、7-Eleven、全家**
    *   **理由**：門市密度高，用戶覆蓋率廣。全聯的促銷週刊結構化程度高，易於抓取商品級優惠；7-11 與全家雖優惠封閉在 LINE/App，但用戶習慣透過 LINE 接收優惠，可考慮先抓取「LINE 官方帳號的公開推播訊息」作為即時性補充。
*   **次選：麥當勞、肯德基、85°C、星巴克**
    *   **理由**：品牌認知度高，官網結構化程度中等，適合展示「會員日」或「限定商品」等長期優惠。
*   **避開（初期）**：小型連鎖店（如吉野家、漢堡王）或資料極度封閉的店家，因為維護成本高，且用戶搜尋頻率較低。

#### 2. 建議的技術做法

1.  **門市位置資料**：
    *   **首選**：使用 **Google Maps Platform**（付費，但資料最準確、即時，且支援 Geocoding 與 Place Search）。
    *   **次選**：使用 **OpenStreetMap (OSM)** + **Overpass API**（免費，但需自行清洗資料，且部分台灣店家資料可能滯後）。
    *   **備選**：爬取各店家官網的「門市查詢」頁面（需處理 JS 渲染，使用 Puppeteer 或 Playwright）。

2.  **優惠資訊抓取**：
    *   **結構化網頁**：針對全聯、麥當勞、肯德基等官網的「促銷」或「優惠」頁面，使用 **Scrapy** 或 **BeautifulSoup** 定期抓取（例如每日凌晨）。
    *   **LINE 官方帳號**：使用 **LINE Messaging API** 或第三方工具（如 LINE Bot 框架）接收官方帳號的群發訊息。需解析訊息中的文字與圖片，提取優惠資訊。
    *   **App 逆向工程**：針對 7-11、全家、星巴克等核心優惠在 App 內的店家，可考慮逆向工程 App 的 HTTP 請求（使用 Charles Proxy 或 mitmproxy），找到公開的 JSON API 端點。但需注意 Cookie/Token 的過期問題。
    *   **人工輔助**：初期可考慮半自動化，由人工每週更新一次「重點優惠」，並標註「最後更新時間」。

3.  **資料結構化**：
    *   建立統一的資料模型：`{ store_name, category, location, promotion_title, promotion_description, start_date, end_date, applicable_stores, source_url }`。
    *   對於「適用門市」，需將優惠與門市 ID 關聯。若優惠為「全門市」，則標記為 `all`；若為「特定門市」，則需解析門市列表。

#### 3. 主要風險

1.  **資料即時性與準確性**：
    *   優惠資訊可能隨時變動（例如：庫存售罄、活動提前結束），若抓取頻率不足，用戶可能看到過期資訊。
    *   **對策**：標註「最後更新時間」，並建議用戶以門市實際公告為準。

2.  **LINE/App 生態系的封閉性**：
    *   許多優惠僅在 LINE 或 App 內可見，且需登入會員帳號。逆向工程 App 可能因版本更新而失效。
    *   **對策**：優先抓取官網公開資訊，LINE 訊息作為補充；若逆向工程失敗，可考慮與店家合作取得 API 授權（較困難）。

3.  **門市資料滯後**：
    *   飲料店與便利商店開關店頻繁，官網或 OSM 資料可能滯後。
    *   **對策**：使用 Google Maps 資料，並定期更新（例如每週一次）。

4.  **法律與授權問題**：
    *   爬取官網資料可能涉及「合理使用」或「著作權」問題，尤其是圖片與文字描述。
    *   **對策**：初期僅抓取結構化資料（名稱、價格、日期），避免大量複製圖片；若規模擴大，可考慮與店家合作。

5.  **維護成本**：
    *   各店家網頁結構可能隨時變動，需持續維護爬蟲腳本。
    *   **對策**：使用模組化設計，將每個店家的爬蟲獨立，便於單獨維護與更新。
