# 增量遊戲點子

網頁版優先。參考作品：Bills Must Be Paid、Bottle Flip Inc、Dirt Clicker。

---

## 一、三款參考作品拆解

### Bills Must Be Paid

> Rike Games，Unity WebGL，CrazyGames + Steam，2026

主動點擊型增量遊戲，靠砸存錢筒來繳帳單。

- 砸擊消耗**體力**，手累了這一輪就結束 → 天然的 run-based 結構
- 帳單有**到期日**；不繳，討債的會從之後所有收入抽成
- 豬公掉**隨機戰利品**
- 收集系統：豬公、鎚子、硬幣、戒指、手環
- **最關鍵的設計**：錢有兩個互相衝突的用途——付下一張帳單 vs. 在後面的豬公變硬之前先強化 build
- 高利貸角色，每日抽成總額可能是原始借款的數倍
- **破產 = Prestige 重置**，換 Legacy Points

### Bottle Flip Inc

> Gamechill，約 4 小時短篇

- 翻瓶賺錢 → 買「幫手之手」自動化
- 從瓶子取下**瓶蓋**當第二貨幣，餵養技能樹
- 解鎖新瓶子種類 = 內容變化
- 能力把單純翻瓶變成**華麗場面**
- 一個動詞、一個畫面、明確的結局

### Dirt Clicker

> Sailing Bears

- 從一支湯匙和一小塊泥土開始
- 每挖一次：更多泥土 → 新工具 → 新幫手 → 更大技能樹 → **新地層**
- 幫手有個性：蘑菇夥伴、泥土魔像、德魯伊
- 挖出寶物變賣、稀有拼圖碎片、遺物
- **續探 vs. 下潛**的抉擇
- 40+ 物品、能破壞平衡的法術、能看出誰在偷懶的統計頁

### 共通骨架（值得偷走）

| 層次 | 內容 |
|---|---|
| 核心動詞 | 一個手感好、回饋足的動作（砸 / 翻 / 挖） |
| 軟貨幣 | 持續產出，花在會被通膨掉的升級上 |
| 硬貨幣 | 瓶蓋、Legacy Points——重置後保留，餵養技能樹 |
| 自動化 | 有名字、有個性的幫手 |
| 進度軸 | 看得見的空間推進（深度、帳單週期、距離） |
| 張力 | 逼你取捨的限制器（體力、期限、續探 vs 下潛） |
| 收集 | 掉寶與稀有度，獨立於數字線之外的第二獎勵管道 |
| 結局 | 三款都很短。**2–6 小時走到真正結局，遠勝無限刷** |

## 二、技術規劃（通用）

**技術選型**

- Vite + TypeScript
- UI 用純 DOM/CSS；核心動詞若是物理性的才開一個 `<canvas>`
- 在 UI 真的需要之前**別上 React**——增量遊戲不斷重繪，60fps ticker 上做 DOM diffing 是自找麻煩
- 數字超過約 `1e308` 再引入 `break_infinity.js`
- 真的需要物理才用 `matter-js`

**架構原則**

- 單一個可序列化的 `GameState`。無法 `JSON.stringify` 的東西不該進 state
- 固定時間步 tick（每秒 20 次）與 render 解耦，累積剩餘 dt，避免背景分頁掉進度
- 所有升級／幫手／地層／物品都是**資料**（`content.ts`，純物件 + 成本公式函式）。絕不寫死進邏輯——這決定調平衡是 20 分鐘還是一次重構
- 存檔：每 15 秒 + `visibilitychange` 寫 `localStorage`
- 離線收益 = `Date.now() - lastSave`，設上限（2–8 小時），通常 50% 效率結算
- 成本曲線：`cost = base * growth^owned`，growth 1.07–1.15
- 產出：同層級相加，跨層級相乘

**里程碑**

| # | 時程 | 內容 |
|---|---|---|
| 1 | 第 1–2 天 | 只做動詞。點擊 → 數字上升 + 手感（粒子、震屏、音效、數字彈出）。不好玩就換動詞 |
| 2 | 第 1 週 | 6–8 個升級、存讀檔、成本曲線 |
| 3 | 第 2 週 | 自動化層。**遊戲開始自己跑的那一刻就是鉤子** |
| 4 | 第 3 週 | 進度軸（地層／週期）+ 張力機制 |
| 5 | 第 4 週 | Prestige + 技能樹 + 硬貨幣 |
| 6 | 第 5–6 週 | 收集、成就、終局、平衡、手機觸控區 |
| 7 | — | 先上 itch.io，反應好再進 GameDistribution / CrazyGames。**零伺服器依賴** |

## 三、10 個點子

### 1. 雪花球公司（Snow Globe Inc.）

搖雪花球，亮片落下變成金幣。核心動詞是拖曳搖晃＋粒子物理。幫手是球裡的小人偶，從內部幫你搖。進度軸是一排展示架，每顆新球是一個生態區、有各自掉寶表。Prestige = 球裂開，保留亮片。canvas 粒子成本低但畫面漂亮。

### 2. 討債模擬器

把 Bills Must Be Paid 反過來——你是討債的那一方。敲門、擊破藉口、收錢。張力機制是**名聲**：逼太緊整個街區不再開門，收入被掐住。幫手是越來越失控的合夥人。道德弧線給遊戲真正的結局。純 DOM，不需物理。

### 3. 堆肥點擊（Compost Clicker）

把廚餘變成土壤。步調慢、療癒。核心動詞是丟廚餘上堆，堆會肉眼可見長高變深。兩貨幣：體積（軟）／腐植質（硬）。幫手是蚯蚓、鼠婦、真菌——真實分解者、真實功能，升級樹能教東西。地層 = 挖自己堆出來的層理。美術便宜（軟塊狀 SVG）。

### 4. 電梯公司（Elevator Inc.）

一部電梯，無限樓層。乘客按樓層數付費，所以**進度軸本身就是錢**。張力在載客量 vs. 速度 vs. 耐性。幫手是額外電梯井。Prestige = 打掉重蓋更高的樓。

→ **詳細設計已獨立成篇：[[elevator inc]]**

### 5. 麵包發酵（Bread Rise Idle）

折疊麵團、等待發酵、烘烤、販售。妙處在**等待是機制而非懲罰**——發酵時間就是資源，升級買的是更好的發酵而非更快的點擊。幫手是有名字有情緒的酵頭（疏於照顧會死）。Prestige = 用保存的酵頭碎片養新的，保留「血統」加成。

### 6. 打水漂（Skipping Stones）

甩石過水面，每次彈跳就是收益。彈跳次數天生是指數獎勵，數值骨架白送。進度軸是湖擴張成海。收集品是 40+ 石頭，重量形狀改變甩擲手感。動詞極舒服，但也是最難調對的部分。

### 7. 垃圾信過濾（Spam Filter）

分類信件，點掉垃圾、留下真信。收入來自按正確分類計費的企業合約。張力：誤殺有代價，信件湧入快過你能讀。自動化 = 訓練過濾器（假的 ML 樹），主題完美契合，因為**自動化正是題材本身**。終局：過濾器產生自我意識。零美術預算。

### 8. 深海打撈

Dirt Clicker 的結構泡在水裡。潛艇往下穿越海洋層。**水壓是體力的對應物**——潛得比船殼耐壓深，可能失去本輪貨物，製造真正的「再下一層 vs 現在上浮」抉擇。幫手是遙控載具、受訓章魚。掉寶是 40+ 沉船文物附背景敘述。一張漸層背景就有高美術投報率。

### 9. 魯布・戈德堡公司（Rube Goldberg Ltd.）

每次「點擊」是把彈珠丟進裝置；彈珠觸發連鎖，鏈上每個元件都在乘算報酬。升級會實際在畫面加裝零件，所以**升級樹就是視覺本體**。這是「遊戲逐漸變成表演」最強的版本。做起來較難（需確定性連鎖模擬，非完整物理），但截圖與傳播天花板最高。

### 10. 房東帳本（Landlord's Ledger）

結構上最貼近 Bills Must Be Paid。繼承一間快垮的出租單位。租金月付、維修隨機、房貸是期限。錢的雙重用途張力完全成立：還債 vs. 整修。高利貸對應角色是掠奪性再融資業者。Prestige = 法拍，保留經驗點。加一條租客滿意度作第二軸避免淪為純算術。**十個裡最快做得出來**。

### 選擇建議

- **最快出貨**：4、7、10（無物理、無美術產線）
- **天花板最高**：6、9（但手感是生死線，先只做核心動詞原型）
- **辨識度最高**：3、5
